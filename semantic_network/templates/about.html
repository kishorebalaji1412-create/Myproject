Semantic Network Visualization

A powerful web-based tool for visualizing and exploring semantic networks built from real-world datasets. This application combines Flask, D3.js, and Kaggle API integration to transform raw data into interactive, beautiful network visualizations.

Features

  • Kaggle Integration: Search and download datasets directly from Kaggle
  • Automatic Analysis: Intelligently extracts semantic relationships from data
  • Interactive Visualization: Explore networks with zoom, pan, and drag
  • Smart Search: Find nodes and filter by category in real-time
  • Dark/Light Mode: Toggle themes for comfortable viewing
  • Export Functionality: Download network data as JSON
  • Mobile Responsive: Works seamlessly on desktop, tablet, and mobile
  • Real-time Statistics: View network metrics and dataset information

Technology Stack

Backend

  • Flask: Python web framework
  • NetworkX: Network analysis library
  • Pandas: Data processing and analysis
  • Kaggle API: Dataset access and download
  • scikit-learn: Machine learning utilities

Frontend

  • D3.js: Interactive data visualization
  • HTML5/CSS3: Modern web standards
  • JavaScript ES6+: Dynamic interactions
  • Jinja2: Template rendering

How It Works

  1. Search & Download: Use the dataset browser to search Kaggle and download any CSV dataset
  2. Automatic Processing: The system analyzes the CSV and detects the best columns to use for creating nodes and relationships
  3. Network Building: NetworkX creates a semantic graph where nodes come from data values and edges represent relationships
  4. Interactive Visualization: D3.js renders the network with force-directed layout, allowing exploration and analysis
  5. Analysis & Export: View node details, filter by category, search terms, and export the network data

Getting Started

  1. Go to the Dataset Browser
  2. Search for any dataset (e.g., "iris", "housing", "covid")
  3. Click "Load Dataset" to download and process it
  4. The semantic network will automatically visualize
  5. Interact with the graph: click nodes, search, filter by category
  6. Export the network as JSON for further analysis

Kaggle API Setup

To use the Kaggle integration, you'll need to set up your Kaggle credentials:

  1. Visit kaggle.com/account
  2. Click "Create New API Token" to download kaggle.json
  3. Place kaggle.json in your project root or ~/.kaggle/ directory
  4. Update .env with your Kaggle credentials if needed
  5. Restart the Flask application

Use Cases

  • Data Exploration: Visually explore relationships in complex datasets
  • Knowledge Graphs: Create semantic webs from categorical data
  • Social Network Analysis: Analyze connections and communities
  • Entity Relationships: Understand how entities relate and interact
  • Pattern Discovery: Identify hidden relationships and clustering patterns
  • Data Documentation: Visualize data structure and relationships
